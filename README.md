# Kyle Ferguson — Portfolio

A lightweight, responsive portfolio for `https://kyleferguson91.github.io/Portfolio/`.

## Content focus

The site presents Kyle's IT support, automation, and software-development work in a concise format. Stricklands work is described generally; internal source, screenshots, customer information, locations, and system details are not published. Personal software examples link to their public GitHub repositories.

## Files

- `index.html` — accessible single-page portfolio
- `styles.css` — responsive styling; no framework or build step
- `favicon.svg` — simple text favicon
- `toolbox-overview.jpg`, `toolbox-review.jpg` — sanitized captures of Kyle's live toolbox interface, with no selected computer or internal workspace information

The legacy `script.js` path is retained as an empty compatibility file and is not loaded by the site. Screenshots document the interface; they do not imply that operational tools were run during the portfolio work.

The GitHub Pages project site is served from the `Portfolio` repository's default branch. Keep the canonical URL and LinkedIn destination aligned if the project is moved.
