# Kyle Ferguson | Portfolio

My personal site, with IT support experience, tools I have built, and projects from my Computer Programming education.

[View the portfolio](https://kyleferguson91.github.io/Portfolio/)

## About the site

Built with HTML, CSS and a small amount of JavaScript. There is no framework or build step. Open `index.html` to view it locally. GitHub Pages serves the site from this repository.

The projects include a standalone Windows IT Toolbox, PC migration workflows, business trackers, and Java and Android applications. Workplace examples use general descriptions and sanitized screenshots.

## Files

- `index.html`: page content
- `styles.css`: layout and styling
- `script.js`: active-section navigation
- `images/` and the root JPG files: project screenshots and sharing image
- `output/pdf/Kyle-Ferguson-Resume.pdf`: downloadable resume

## Design references

I took layout and writing inspiration from [Brittany Chiang](https://brittanychiang.com/), [Lee Robinson](https://leerob.com/) and [Lynn Fisher](https://lynnandtonic.com/).
